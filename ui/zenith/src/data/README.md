# Bundled data

`places.txt` is the offline nearest-town table for the Home page Location. It is generated by
`tools/gen-places.py` from GeoNames `cities1000` and `admin1CodesASCII`.

Place data © [GeoNames](https://www.geonames.org/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The table keeps the name, the region
(US state abbreviation, otherwise the first-level region name) and coordinates rounded to 0.01°.
Neighbourhood, historical and abandoned entries are left out.
